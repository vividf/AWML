## Bin 邊界對齊差異

### 數值示例

假設有一個激活值 `x = 3.14159`：

```
┌─────────────────────────────────────────────────────────────┐
│                    Seed 0 (Width = 0.00171)                  │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  Bin 邊界:                                                  │
│    ...                                                      │
│    Bin 1835: [3.137, 3.139]                                │
│    Bin 1836: [3.139, 3.141]  ← x=3.14159 落在這裡          │
│    Bin 1837: [3.141, 3.143]                                │
│    ...                                                      │
│                                                             │
│  分配: Bin 1836, count += 1                                │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│                    Seed 1 (Width = 0.00205)                  │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  Bin 邊界:                                                  │
│    ...                                                      │
│    Bin 1531: [3.139, 3.141]                                │
│    Bin 1532: [3.141, 3.143]  ← x=3.14159 落在這裡          │
│    Bin 1533: [3.143, 3.145]                                │
```

**結果**: 相同的數值被分配到不同的 bin！

## 關鍵影響點總結

### 1. 第一個 Batch 的決定性作用

```
第一個 Batch 的最大值 → 決定初始 Histogram 範圍
                    → 決定 Bin 寬度
                    → 決定後續所有 Batch 的 Bin 分配
                    → 影響最終 Histogram 形狀
                    → 影響 MSE 優化的最優 amax
```

### 2. Bin 寬度差異的放大效應

```
Width 差異: 0.00171 vs 0.00205 (19.9% 差異)
    ↓
Bin 邊界對齊不同
    ↓
相同數值分配到不同 Bin
    ↓
Histogram 分佈不同
    ↓
MSE 優化結果不同
```

### 3. 多層累積效應

```
單層 amax 差異: 0.006 (0.18%)
    ↓
10 層累積: 誤差放大
    ↓
最終 mAP 差異: 0.005 (0.5%)
```

## 實際數據流示例

### Seed 0 的數據流

```
DataLoader (Seed 0)
  │
  ├─> Batch 1: [sample_50, sample_120, sample_3, ...]
  │     └─> max_activation = 3.5
  │           └─> Histogram: [0, 3.5], width=0.00171
  │
  ├─> Batch 2: [sample_200, sample_15, sample_88, ...]
  │     └─> max_activation = 3.2
  │           └─> Histogram: 累積到 [0, 3.5]
  │
  ├─> Batch 50: [sample_500, sample_1, sample_999, ...]
  │     └─> max_activation = 4.2
  │           └─> Histogram: 擴展到 [0, 4.2], width=0.00171
  │
  └─> Batch 938: [sample_2, sample_800, sample_45, ...]
        └─> max_activation = 3.8
              └─> Histogram: 累積到 [0, 4.2]
                    └─> MSE 優化: amax = 3.245
```

### Seed 1 的數據流

```
DataLoader (Seed 1)
  │
  ├─> Batch 1: [sample_500, sample_1, sample_999, ...]  ← 不同順序！
  │     └─> max_activation = 4.2
  │           └─> Histogram: [0, 4.2], width=0.00205
  │
  ├─> Batch 2: [sample_50, sample_120, sample_3, ...]
  │     └─> max_activation = 3.5
  │           └─> Histogram: 累積到 [0, 4.2]
  │
  ├─> Batch 50: [sample_200, sample_15, sample_88, ...]
  │     └─> max_activation = 3.2
  │           └─> Histogram: 累積到 [0, 4.2]
  │
  └─> Batch 938: [sample_800, sample_2, sample_45, ...]
        └─> max_activation = 3.8
              └─> Histogram: 累積到 [0, 4.2]
                    └─> MSE 優化: amax = 3.251  ← 不同結果！
```

## 結論

**核心問題**: Histogram 累積的順序敏感性導致不同的 bin 分配和最終不同的 amax 值。

**影響路徑**:
```
Seed → 數據順序 → Histogram 累積順序 → Bin 寬度 → Bin 邊界對齊
  → Histogram 形狀 → MSE 優化 → amax 差異 → 量化誤差 → mAP 差異
```

**解決方案**: 使用固定 seed 確保可重現性，或使用更穩定的校準方法（如 percentile）。
